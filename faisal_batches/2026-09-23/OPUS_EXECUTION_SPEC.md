## 11. ALGORITHMS / LOGIC
**R-01 `news_candle_level(df, news_date, price=None)`** — النموذجُ الأوّليّ جُرِّب (§9 · مِجَسّ ①-⑤):
```
d0  = Timestamp(news_date[:10])
pos = searchsorted(normalize(df.index), d0, side="left")      # أوّلُ جلسةٍ في يوم الإيداع أو بعده
cand = [p for p in (pos, pos+1) if 0 <= p < len(df)]           # الشمعةُ نفسُها أو التالية (خبرٌ بعد الإغلاق)
if not cand: return None
best = argmax over cand by (Volume, -p)                        # الأعلى حجمًا · الأبكرُ عند التعادل
hi, lo = High[best], Low[best];  invalid (non-finite, ≤0, lo>hi) ⇒ None
px = price or Close[-1]
role = "مقاومة فوق السعر" if px < lo else ("دعم تحت السعر" if px > hi else "السعر داخلها")
return {date, open, high, low, close, role, lag = best - pos}
```
