## First-divergence principle
The earliest stage at which the pipeline's state diverges from Faisal's is S4 (candidate generation) for all six rows — upstream
stages (raw data, identity, universe) pass; downstream stages never run. Apparent downstream symptoms (never in the 15-slot list,
never READY, never notified) are consequences of S4, not independent failures. Within S4 the first divergence differs by ticker:
SXTC → M2 ceiling (adjusted-series artefact; H2), HUBC → M4 range (split-window artefact; H2), DKI → anchor rule (H3). The anchor
rule fails on all three independently, which is why Phases 3–4 named it the common first wall.

## Causal root cause — statement
Established (causal, reproducible): each anchor is dropped at candidate generation by a specific, documented predicate whose
inputs are the split-adjusted candle series; for SXTC and HUBC the failing inputs are artefacts of reverse-split accumulation in the
adjusted frame; for DKI (no split) the failing predicate is the two-touch anchor rule. Not established: that any single change
would reproduce Faisal's selections without unacceptable false positives (Phase 2–4 evidence is against single changes), and
whether non-candle information explains Faisal's choices (no historical data existed; Phase 6 collection makes this testable
prospectively). The evidence does not establish a causal root cause for *Faisal's selection*; it establishes the causal
location of the *bot's rejection*.
