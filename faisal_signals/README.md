# 🧾 سجلُّ إشارات فيصل (أمرُ المالك 2026-11-19 · تسجيلٌ فقط)

**الملفّ:** `FAISAL_SIGNAL_LEDGER.jsonl` — إلحاقيّ · صفٌّ لكلّ إشارة · والفاحصُ `python3 faisal_signals/signals.py --check`.

## القواعد (كُتبت قبل أيّ حسم)
1. **الخصوصيّة:** محادثةُ المالك مع فيصل خاصّة ⟵ يُسجَّل **الرمزُ والتاريخُ والسعرُ ونصُّ القراءة** وحدَها · **لا لقطةَ تُدفَع** (المستودعُ عامّ) · والفاحصُ يرفض أيَّ حقلِ صورة.
2. **رجعيّ (`retro`):** مثالٌ ذُكر بعد حركته ⟵ يُسجَّل للتوثيق **ولا يدخل نسبةَ الإصابة أبدًا** (`counts_in_hit_rate: false`).
3. **أماميّ (`forward`):** كلُّ إشارةٍ يرسلها المالك تُسجَّل **لحظةَ وصولها بسعرها** (إغلاقُ دقيقة Polygon عند طابع الوصول) — **الناجحةُ والفاشلة** — وتُحسم بعد **20 جلسة** من جلسة الوصول · وهي **وحدَها** في النسبة.
4. **تعريفُ الإصابة** (افتراضٌ منّي — `engineering` — يقبل تعديلَ المالك **قبل أوّل حسمٍ وحدَه** ثمّ يُجمَّد): بلغ أعلى سعرٍ خلال الجلسات العشرين **+30% فأكثر** فوق سعر الوصول (تعريفُ «تحرّك 30%» المعتمد). ويُسجَّل مع كلّ حسم: أقصى صعود % · أعمق هبوط % · إغلاقُ الجلسة العشرين · وهل تحقّق السيناريو الموصوف نصًّا (وصفٌ لا حكم).
5. **لماذا سجلٌّ مستقلّ لا `PROSPECTIVE_LEDGER`/H6/`T-FSWEEP`:** تلك السجلّاتُ مختومةٌ ببروتوكولاتٍ مجمَّدة تشترط صورةً وختمًا قبل V4 · وهذه إشاراتٌ نصّيّة من محادثةٍ خاصّة بلا صورة ⟵ إدخالُها هناك تغييرٌ لعقدٍ مجمَّد.
6. لا إنتاج · لا تلغرام · لا عتبة · والسجلُّ لا يقرؤه كودُ البوت.
